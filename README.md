# @dsh-external/dsh-client-ui-subagent-model-picker

DSH 的「插件配置」卡片：让用户为每个 `provider/model` 填写能力描述。
读写 `subagent-model-picker` 设置命名空间（由宿主导签 `dsh-subagent-model-picker` 注册），
`list_subagent_models` 随后会带出这些描述。

安装：`dsh plugin --profile web add github:cczzyy-cn/dsh-client-ui-subagent-model-picker#v0.1.0`
